## Local development

The React client now runs on Vite. Start the Flask API first, then start the client:

```powershell
cd flask-api
python -m flask --app api run --no-debugger
```

```powershell
cd react-client
npm install
npm run dev
```

Open `http://127.0.0.1:3000`.
